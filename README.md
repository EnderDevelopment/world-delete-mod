# World Delete Mod

Server-side world deletion with confirmation for Fabric Minecraft.

## Features

- Server-side command `/world_delete` for OP level 4
- Broadcasts confirmation message with clickable buttons
- Executes world deletion upon confirmation

## Requirements

- Minecraft 26.3
- Fabric Loader 0.14.22 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

### Commands

| Command | Permission Level | Description |
|---------|------------------|-------------|
| `/world_delete` | 4 | Broadcasts a confirmation message with clickable buttons. |
| `/confirm_world_delete` | 4 | Executes the world deletion. |

No additional configuration is required.
